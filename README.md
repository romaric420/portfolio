# Portfolio – Romaric TCHOFFO

Portfolio de Data Scientist & ML Engineer (React + Vite).

## Lancer en local

```bash
npm install
npm run dev
```

## Mettre à jour le contenu

- Textes FR / EN : `src/locales/fr.json` et `src/locales/en.json`
- Projets (tags, liens, images) : `PROJECTS_CONFIG` dans `src/components/Projects.jsx`
- CV : `public/cv/` (mettre à jour le nom du fichier dans `Navbar.jsx` et `Contact.jsx`)
